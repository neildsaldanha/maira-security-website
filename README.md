# Maira Security – website redesign concept

A concept redesign for [Maira Security & Facility Services](https://mairasecurity.com), Bannerghatta Road, Bangalore. **This is not the live site.** Items marked `CONFIRM` are waiting on details from the owner.

## What's in it

- Night-to-dawn scroll scene, drawn in code (no video, works on phones)
- Service explorer with real team photos
- Quote builder that writes a WhatsApp or email message
- Licence and certificate cards
- On-the-ground photo gallery with a full-screen viewer
- Founder section, process steps, FAQ, contact

## Files

- `index.html` – the whole site: one file, plain HTML, CSS and JavaScript, no build step
- `maira-hero/hero-prompts.md` – AI image and video prompts kept for a possible future hero video
- `robots.txt` – keeps this concept out of search engines

## Viewing

Open `index.html` in a browser, or use the GitHub Pages link for this repo. Photos load from mairasecurity.com, so an internet connection is needed.
